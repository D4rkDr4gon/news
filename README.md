# news

Brief semanal (IT, ciberseguridad, IA y Argentina) publicado en https://lcampassi.com/news

Lo genera una rutina de Claude Code cada lunes 09:00 ART:
- `briefs/YYYY-MM-DD.md` — el brief de la semana en Markdown
- `briefs/index.json` — índice `[{date, title, headlines[]}]`
- `index.html` — portal estático que renderiza los briefs
